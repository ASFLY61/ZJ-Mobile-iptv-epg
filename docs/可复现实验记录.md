## 实验 1:STBRegister(设备注册)

### 目的
在服务器登记 STB,激活认证状态;取 UserID 与加密 Password。

### 请求(精确字节)
```
POST http://YOUR_EDS_HOST:PORT/EDS/STBRegister
Content-Type: text/xml; charset=UTF-8

<STBRegisterReq><STBID>YOUR_STBID</STBID></STBRegisterReq>
```

### 中间值:307 重定向
```
HTTP 200(入口)→ 307 Location: http://YOUR_VSP_IP:7176/EPG/XML/STBRegister
```
> 入口 `YOUR_EDS_HOST:PORT` 只是跳板,真实处理在 `YOUR_VSP_IP:7176`。
> 注意:本次 STBRegister 落到 **7176**,而后续 challenge/Digest 落到 **7183**——端口每次请求都可能不同。

### 响应
```xml
<?xml version="1.0" encoding="UTF-8"?>
<STBRegisterRes>
  <STBRegisterRsltCode>0</STBRegisterRsltCode>
  <Description>Success</Description>
  <UserID>YOUR_USERNAME</UserID>
  <Password>UnpueFds%2BkEb0R%2B7vNsOGg%3D%3D</Password>
</STBRegisterRes>
```

### 中间值:Password 解码链
```
原始(URL 编码) : UnpueFds%2BkEb0R%2B7vNsOGg%3D%3D
  └─ URL 解码   : UnpueFds+kEb0R+7vNsOGg==
  └─ Base64 解码: <32 字节 AES 密文>
  └─ 明文(静态): YOUR_PASSWORD
```
> 本方案**不解密**这个 AES 密文——明文 `YOUR_PASSWORD` 已知且静态,直接硬编码。

### 验证
- `STBRegisterRsltCode == 0` → 注册成功。
- `UserID == YOUR_USERNAME` → 与 ADB `ro.serialno` 对应订购一致。

### 来源
URL/body 格式:反编译 `AuthenticatePresenter` 登录链 + `yidong.pcapng` 抓包;STBID:ADB `ro.serialno`;307 行为:抓包 + 实测。

## 实验 2:Digest Challenge(取挑战)

### 目的
取 Digest 认证参数(realm/nonce/opaque/algorithm/qop)。

### 请求(精确字节)
```
POST http://YOUR_EDS_HOST:PORT/EDS/pub/authentication_initial_challenge_v1
Content-Type: text/plain; charset=UTF-8

(空 body)
```

### 中间值:307 重定向
```
HTTP 200(入口)→ 307 Location: http://YOUR_VSP_IP:7183/EPG/XML/authentication_initial_challenge_v1
```
> 本次落到 **7183**——这个端口后来正是 ZJLogin 的工作端口(见实验 4)。

### 响应
```
WWW-Authenticate: Digest realm="YOUR_REALM",nonce="YOUR_NONCE",opaque="",algorithm="MD5",qop="auth-int"
```

### 中间值:字段解析
| 字段 | 值 | 说明 |
|---|---|---|
| realm | `YOUR_REALM` | 认证域 |
| nonce | `YOUR_NONCE` | 服务器随机数 |
| opaque | `` (空) | 透传 |
| algorithm | `MD5` | 哈希 |
| qop | `auth-int` | **HA2 必须带 body 哈希** |

### 验证
- 解析出的 5 个字段齐全,`qop=auth-int` 确认走完整性保护分支。

### 来源
URL:反编译 `AuthManagerImpl`;解析规则:RFC 2617 + 实测;`qop=auth-int` 决定 HA2 形式:反编译 + 抓包。

## 实验 3:Digest Authentication(加密核心,中间值最全)

### 目的
用 STBID + 密码算 `Authorization: Digest ...`,换 UserToken。

### 请求(精确字节)
```
POST http://YOUR_EDS_HOST:PORT/EDS/pub/authentication_initial
Content-Type: text/xml; charset=UTF-8
Authorization: Digest realm="YOUR_REALM",nonce="YOUR_NONCE",opaque="",algorithm="MD5",qop="auth-int",userid="YOUR_USERNAME",nc="000000001",cnonce="<32hex>",response="<32hex>"

<?xml version='1.0' encoding='UTF-8' standalone='yes' ?><AuthenticationRequest><STBID>YOUR_STBID</STBID></AuthenticationRequest>
```

### 中间值:完整计算链(已用 verify_digest.py 复算验证)

**[1] BASE64(password)**
```
password  = "YOUR_PASSWORD"
base64    = "BASE64(YOUR_PASSWORD)"
```

**[2] HA1 = MD5(username:realm:BASE64(password))**
```
输入 = "YOUR_USERNAME:YOUR_REALM:BASE64(YOUR_PASSWORD)"
HA1  = YOUR_HA1
期望 = YOUR_HA1   → OK
```

**[3] MD5(body)**(body 字节级精确,`?>` 前必须有空格)
```
body = "<?xml version='1.0' encoding='UTF-8' standalone='yes' ?><AuthenticationRequest><STBID>YOUR_STBID</STBID></AuthenticationRequest>"
len  = 150 bytes
MD5  = YOUR_BODY_MD5
期望 = YOUR_BODY_MD5   → OK
```

**[4] HA2 = MD5("POST:/EDS/pub/authentication_initial:" + MD5(body))**
```
输入 = "POST:/EDS/pub/authentication_initial:YOUR_BODY_MD5"
HA2  = YOUR_HA2
期望 = YOUR_HA2   → OK
```

**[5] response = MD5(HA1:nonce:nc:cnonce:qop:HA2)**
```
nc     = 000000001        (9 字符,易错点)
cnonce = <MD5(随机整数)>   (每次随机,离线无法复现同一值)
输入   = "YOUR_HA1:YOUR_NONCE:000000001:<cnonce>:auth-int:YOUR_HA2"
response = <32hex>
```
> 演示(固定 cnonce=MD5("12345")=827ccb0eea8a706c4c34a16891f84e7b):
> `response = e069bbf52a5aa8ff69664508ce775d49`
> 真实运行的 response 因 cnonce 随机而不同,但公式与 HA1/HA2 已验证一致,服务器端重算比对即通过。

**[6] 反例(复现 20244 根因):body 的 `?>` 前少一个空格**
```
body(错) = "<?xml version='1.0' encoding='UTF-8' standalone='yes'?><AuthenticationRequest>..."
MD5(错)  = a60002925fb6dbd0837bf1642d2c3127
HA2(错)  = 02775f76f9c500cd93baa71620605923
→ 与正确 HA2 不同 → response 不同 → 认证失败(20244)
```

### 中间值:307 重定向
```
HTTP 200(入口)→ 307 Location: http://YOUR_VSP_IP:7183/EPG/XML/authentication_initial
```
> 落点 **7183** = 当前 edsUrl 端口 → 直接作为 ZJLogin 的 hint(实验 4 一次命中)。

### 响应
```xml
<?xml version="1.0" encoding="UTF-8"?>
<AuthenticationResponse>
  <StatusCode>0</StatusCode>
  <UserToken>YOUR_USERTOKEN</UserToken>
  <ValidFrom>20260918194403</ValidFrom>
  <ValidTo>20260919194403</ValidTo>
</AuthenticationResponse>
```

### 验证
- `StatusCode == 0` → 认证成功。
- `UserToken = YOUR_USERTOKEN`,有效期 24h(ValidFrom→ValidTo)。
- HA1 / MD5(body) / HA2 三项与实测基准**逐位一致**(verify_digest.py 输出 OK)。

### 来源
算法:反编译 `AuthManagerImpl.java:434-471`;nc=9 字符:反编译 `countCN(1)`;body 精确字节(空格):Frida `get_body.py` 调盒子 `XMLParseCls.getPostInfo` 实抓 + `verify_body.py` 复算 MD5 一致。
